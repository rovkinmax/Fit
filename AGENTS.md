# Fit Engineering

Follow the installed Kent Engineering Kit skill and the active node context
manifest. Native Workflow state owns task lifecycle; project documents do not.
Use Russian for user-facing communication and English for source artifacts.

Fit uses R2-only durable documents. No legacy bootstrap, `.todo` fallback,
legacy import or automatic migration is authorized. Resolve native storage
through the qualified installation; a proposed profile is not installation
authority. Local cache, ledger and checkpoint obligations belong only to the
selected Workflow route, not to R2 storage in general.

Preserve unrelated changes. Reproduce defects before production fixes. Use
supported Kent worktree operations; preserve ambiguous ownership and effects.
Never fabricate runtime identities, approval provenance or verification results.
Do not commit, push or publish without applicable task authority.

Checked pull requests target `rovkinmax/Fit`, base `main`. Merge, auto-merge
and direct pushes to `main` require separate explicit human confirmation:
`main` publishes production. PR permission does not grant publication permission.

Workflow, adapter, role and Kent configuration changes require an exact preview,
two independent read-only PASS reviews of the same preview hash and explicit
human approval before mutation. Installation and activation are separate effects.
