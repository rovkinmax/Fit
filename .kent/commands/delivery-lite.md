# Lite checked PR delivery

The only repository is `rovkinmax/Fit`; the only PR base is `main`.
Native execution remains pinned to its own actual task baseline. Record the
moving `main` tip separately; integrate it only through an authorized normal
task operation followed by fresh verification and independent candidate review.

Before publishing, verify the incoming exact immutable plan and independent
review result, exact candidate commit/tree, verification result and independent
candidate review. Any mismatch returns to the responsible upstream stage.
Use applicable publication permission; if absent, request it and remain here.
Inspect the entire candidate including relevant staged, unstaged and untracked
files. Preserve unrelated changes. No fake/no-change PR or unrelated diff.

Create or inspect the actual PR and record its number, URL, head SHA, base,
repository and observed check results. The head must equal the reviewed
candidate; require a clean recoverable task tree before advancing.
Observe actual required GitHub checks for that exact head, not merely a green
workflow name or an empty checks list. Missing, pending or unavailable checks
remain blocked/waiting. Failures return to Implement, Verification and
Candidate Review. Any changed PR head invalidates old verification/review/CI.

PR permission grants neither auto-merge nor merge. `main` publishes production.
Ask for separate explicit human confirmation for the exact checked PR/head and
merge effect. Remain in Observe until authorized merge and actual merged-state
readback, or an authorized non-delivery disposition. Do not close the Task as
delivered just because a checked PR exists. Report the checked PR milestone
without claiming full lifecycle completion.

Never push directly to `main`, activate auto-merge, change branch protection or
disable checks. Preserve CI logs/evidence and exact PR/base/head provenance
outside the retiring worktree before Cleanup.
