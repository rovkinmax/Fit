# Delivery Context

Required:
- `AGENTS.md`, `.kent/project-contract.md`, `.kent/workflow-profile.toml`.
- Current gate evidence, external R2 accepted snapshot identity,
  exact task branch/HEAD and delivery authority.
- Active procedure: `.kent/commands/ship-pr.md`, `ci.md`, `waiting-pr.md`
  or `cleanup-task.md`.

Conditional:
- Cleanup: exact resource ownership, retained evidence, merged PR witness,
  installed Kit durable-context reference for external accepted state and
  optional local-cache retirement on the selected Script Janitor route.
- CI: exact PR head/base observations and validated CI contract.
- Damaged evidence: installed Kit evidence-recovery contract.

Preserve exact outgoing carriers. Do not derive a PR base from the task branch.
